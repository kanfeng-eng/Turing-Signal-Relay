## 定稿步骤

3 号为每项提供“场景输入 → 两种解释及取舍 → 推荐解释 → 期望状态/得分”。用户/规则负责人批准后记录决定、日期和批准来源，再由对应成员实现测试。

演示阶段如果必须使用暂定值，配置标记 `provisional` 并记录选择；不能把演示结果称为正式比赛成绩。规则冻结前 OPEN 项必须清零，正式配置变更需更新规则哈希和发布说明。
